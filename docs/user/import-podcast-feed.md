# Import a podcast feed as a playlist

Turn episodes from a podcast feed into a Yoto playlist. OpenMyo downloads the episodes you pick and uses the show's artwork as the cover.

## Prerequisites

- You're signed in to Yoto.
- The link to the podcast's feed.

## Import episodes

1. On the **Import** screen, choose **From Feed…**. You can also paste a feed link anywhere on the screen.
2. Paste the feed link and choose **Preview** to list the episodes. The latest 100 are ticked, because a playlist holds up to 100 tracks.
3. Optional: narrow the list.
   - **Length**: set from and to values, in minutes.
   - **Exclude titles with**: for example `trailer, bonus`.
   - **Only titles with**: keep only matching titles.

   Hidden episodes are never downloaded.
4. Set **Order** to oldest or newest first. This applies both to the list and to the card.
5. Change the ticks as needed, then choose **Download & Add**.

   The episodes download into a temporary folder and appear as a draft named after the show, with the show's artwork as its cover.
6. Review the draft like any other import. You can change the name and cover, then choose **Create Playlists**.

> [!NOTE]
> The downloaded files are deleted once the playlist is created or the draft is discarded.
