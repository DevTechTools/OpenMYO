# Browse and search your library

The library shows your playlists as a list or a grid of covers. Use filters and search to find what needs attention, then act on several playlists together.

## Prerequisites

- You're signed in to Yoto.

## Filter the library

1. Open the library.
2. Switch between the list and the grid of covers.
3. Use the filter chips to show playlists with no tracks, missing icons or missing covers.

## Run bulk actions

1. Select several playlists.
2. Choose an action to match their icons or delete them together. For icon matching, see [Match icons to tracks](match-icons.md).

## Search playlists and tracks

1. Type in the library's search field. It finds playlists by title and tracks by title, across every playlist.
2. Read the results. Matching tracks are listed under their playlist with the matched words highlighted.
3. Select a track to open its playlist at that track, ready to play.

Every word you type must appear, in any order, ignoring capitals and accents. For example, "gruff child" finds "The Gruffalo's Child".
